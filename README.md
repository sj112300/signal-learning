# 信号与系统 · 诊断式学习小模型

郑君里《信号与系统》（第三版）第 1–4 章的自适应学习原型。核心闭环：**测 → 诊断 → 补弱（先补前置）→ 再测**。

单文件实现，零构建、零后端、离线可用。题目**按配置即时生成**，不再维护固定题目列表；支持**波形 / 频谱 / 框图 / 零极点图形题干**与**边做边问的讲解助手**。作答记录存在浏览器 localStorage。

## 怎么打开

- 双击 `打开学习系统.command`（推荐，用默认浏览器打开，进度正常保存）
- 或者直接双击 `index.html`

> 不要用 IDE / 工作台的 iframe 预览面板打开：沙箱会禁用 localStorage，页面仍能做完整轮测试，但刷新后进度会丢。页面更新后如仍是旧版，硬刷新一次（⌘⇧R）。

## 出题配置

首页「出题配置」卡片，五个维度每轮生效，配置自动记忆：

| 配置 | 取值 | 说明 |
|---|---|---|
| 题型 | 概念判断 / 计算求解 / 性质应用 / 系统判别 | 选择题模类别，可多选 |
| 知识点范围 | 15 个知识点（按章分组） | 全选 / 全不选 / 仅薄弱点 快捷按钮 |
| 难度 | 易 / 中 / 难 | 影响题模里的数值范围与变式（难度 3 会出现非周期信号等陷阱变体） |
| 题目数量 | 3–30 题 / 轮 | 默认 10；去重不足时自动补足，标题会显示「去重后 N 题」 |
| 含图形题 | 开 / 关（默认开） | 开启后每轮保证约 20% 为图形题；关闭则全部为文字公式题 |

「再练一轮薄弱点」会自动把知识点范围临时收窄为薄弱点，再生成一批**全新**题目；「完整重测」按当前配置重新生成。

做题时右下角「问一问」打开讲解助手：递进提示、讲知识点、补前置、分析选项、说明符号规范、看完整解析。不填 AI 接口也能用，全部内置离线。

### 生成的题目长什么样

`generateQuestions()` 返回的元素与旧版固定题库结构**完全一致**，下游渲染、判分、统计代码无需改动：

```js
{
  id: 12,                       // 全局唯一数字 id，跨轮不重复
  kp: 'k09',                    // 知识点 id
  type: 'property',             // 题型（新增字段，下游不依赖）
  d: 2,                         // 难度 1-3
  q: '若 \\( f(t)\\leftrightarrow F(\\omega) \\)，则 \\( f(t-3) \\) 的傅里叶变换是：',
  opts: ['...','...','...','...'],   // 4 个选项，已随机洗牌
  a: 2,                         // 正确选项下标（随洗牌变化）
  exp: '时移性质 ...',           // 解析
  mis: ['m02', null, 'm03', 'm03'],  // 阶段 A：与 opts 逐位对应的错因；正确项为 null
  kps: [{id:'k09',w:1},{id:'k08',w:0.35}],  // 阶段 A：Q-matrix 行
  scope: 'iso'                 // 阶段 A：iso 隔离题 / int 综合题
}
```

图形题在上面基础上额外带 `fig`（内联 SVG 字符串）、`figCap`（图注）、`hints`（递进提示）与 `hasFig:true`；渲染层按 `hasFig` 决定是否显示图框，文字题字段一字未改。

阶段 A 新增的两个字段都是**增量字段**：旧的下游渲染、判分、掌握度代码不依赖它们，新增的错因逻辑才读取。

### 加一个题模

在 `TEMPLATES` 区追加一条 `T(...)`。题模返回「题干 + 正确项 + 3 个干扰项 + 解析」，洗牌、答案下标、校验都由 `normalizeQuestion()` 统一处理：

```js
T('t32','calc','k15','新的稳定性题模', d=>{
  const a=ra(d);
  return {
    q:M('H(s)=\\dfrac{1}{s-'+a+'}')+' 的因果系统是：',
    correct:'不稳定的',
    distractors:['稳定的','临界稳定的','无法判断'],
    exp:'极点 '+M('s='+a)+' 在右半平面，故不稳定。'
  };
});
```

统一用 `M('...')` 生成公式块（运行时产出 `\( ... \)`），**禁止**在公式块外写 `e^{3t}`、`1/(s+4)`、`t₀`、`0⁻`、`t²` 这类裸 LaTeX 或 Unicode 上下标——同一页里一半 KaTeX 数学体、一半纯文本会严重干扰符号辨认。

要点：所有数学一律 `M()`；`distractors` 恰好 3 个且与正确项内容不同；`kp` 必须存在于 `KPS`。`normalizeQuestion()` 里 `texIssues()` 会在生成时自动拦截不合规文本并丢弃重试。

新题模建议在 `MIS_MAP` 里登记三个干扰项的错因（或直接在 `gen()` 返回 `mis`）；不登记也能跑，`misFor()` 会按题型给一个可解释的默认错因，但错因画像的精度会下降。

图形题用 `TG(id,type,kp,label,gen)` 注册，只需在返回值里多给 `fig`（由 `figWave()` 等生成）、`figCap` 和 `hints`。

### 符号规范依据

依据 **GB 3102.11—93《物理科学和技术中使用的数学符号》**（等效采用 ISO 31-11:1992，现行对应 **ISO 80000-2:2019**），并参照《图书编校质量差错认定细则》第五十条。核心规则只有一句：**会变的量用斜体，含义或取值固定的用正体**。

| 类别 | 字体 | 例子 |
|---|---|---|
| 变量、参数、一般函数符号、变动附标 | 斜体 | `x, t, s, τ, ω, a, f(t), H(s)` |
| 已定义函数与固定缩写 | 正体 | `sin, exp, ln, Sa, Re, Im, max, lim` |
| 数学常数 | 正体 | `e, π, i`（工程用 `j`） |
| 已定义算子 | 正体 | `d`（微分）、`δ`、`div` |
| 单位、数字 | 正体 | `kHz, ms, rad/s, 3.14` |

《图书编校质量差错认定细则》把「该用正体的字母用了斜体」明确列为编校差错，点名 `e、π、i/j、d、Re、Im`。本系统此前把 `e^{-at}`、`j\omega`、`dt` 排成斜体，现已全部改为 `\mathrm{e}`、`\mathrm{j}`、`\mathrm{d}`。

**例外**：标准要求 π 正体，但常用字体没有正体小写希腊字母（`\uppi` 需额外宏包），按国内外教材惯例保留斜体 `\pi`；其余规则严格执行。

**制度保障**：`texIssues()` 在生成时扫描每个公式块，凡出现裸 `e^`、`j\omega`、`dt`、`d\tau`、`\dfrac{df(` 等就丢弃该题重试；`figIssues()` 对图内公式做同样检查。以后加题模也不会退回旧写法。

### 公式字体（Times New Roman）

按教材与论文惯例，公式中的字母、数字统一用 **Times New Roman**：变量斜体、函数名与常数正体；中文正文仍用系统中文字体，不混用。

实现是在 `vendor/katex/katex.min.css` 之后覆盖 KaTeX 的 `KaTeX_Main` / `KaTeX_Math` 两套字母字体，字体栈为：

```
"Times New Roman", "Times", STIXGeneral, STIXTwoText, KaTeX_Main, serif
```

Times 缺字（希腊字母、数学符号）时退回同为 Times 风格的 STIX，最后才回退 KaTeX 原字体，保证不缺字。**符号字体不替换**：积分号 `∫`、求和号 `∑`、根号 `√`、可伸缩大括号、花体 `\mathcal{F}` 由 `op-symbol` / `delimsizing` / `mathcal` 等专用字体绘制，强行换成 Times 会失去尺寸分级与伸缩能力、公式会散架。已用 10 组公式（分式、积分、求和、大括号、花体、箭头、上下标、根号、极限）在浏览器里验证，计算样式为 `"Times New Roman", Times, STIXGeneral, ...`，符号完整。

### `\mathrm` 是什么

`\mathrm{...}` 是 LaTeX 数学模式里的**正体（罗马体）命令**：花括号内的字母按 upright 排，而不是默认斜体。按 GB 3102.11 / ISO 80000-2，含义或取值固定的符号必须正体，所以系统里写成 `\mathrm{e}`（自然底）、`\mathrm{j}`（虚数单位）、`\mathrm{d}`（微分算子）、`\mathrm{Sa}`、`\mathrm{Re}`、`\mathrm{kHz}`（单位）。

`mathrm` 只是源码里的命令名，**正常渲染后页面只显示字母本身**（例如 `dt`），绝不会显示 `mathrm` 这几个字。截图里出现 `mathrmdt` 属于代码 bug，见下方修复记录。

### 积分号与上下限

定积分统一写成 `\int\limits_{...}^{...}`，让 `−∞`、`∞` 正上正下居中，符合教材写法；不加 `\limits` 时 KaTeX 会把上下限侧置在积分号右上／右下，看起来歪斜。

大运算符仍由 KaTeX 专用数学符号字体绘制。实测把 `.op-symbol.large-op` 换成 STIXTwoMath / STIXIntUpDReg / Times New Roman 后：积分号退化成普通小号 `∫`（专用字体里是放大过的大运算符字形），且上下限按原字形宽度定位，换字体后全部错位、个别字体甚至缺字。因此保留专用符号字体，这是数学排版的通行做法：**Times 风格字母 + 专用数学符号字体**。若要求连积分号本身都是 Times 衬线风格，需要整体换成 MathJax + STIX2 / TeX Gyre Termes Math 方案（替换渲染引擎，另行评估）。

### 符号约定（信号与系统）

| 记号 | 写法 | 说明 |
|---|---|---|
| 抽样函数 | `\mathrm{Sa}` | **必须正体**，斜体 `Sa` 看起来像两个变量相乘；定义 `Sa(x)=sin x / x` |
| 实部 | `\mathrm{Re}(s)` | 正体函数名 |
| 单位 | `\mathrm{kHz}`、`\mathrm{ms}`、`\mathrm{rad/ms}` | 正体，数字与单位间用 `\,` 分隔 |
| 虚数单位 | `\mathrm{j}\omega` | 工程惯例用 j 且必须正体（常数），不用 i |
| 自然对数底 | `\mathrm{e}^{-at}` | 常数正体，不写成斜体 `e` |
| 微分算子 | `\mathrm{d}t`、`\dfrac{\mathrm{d}f}{\mathrm{d}t}` | `d` 是算子不是变量，必须正体 |
| 圆周率 | `\pi` | 标准要求正体，因字体限制按教材惯例保留斜体 |
| 变换算子 | `\mathcal{F}`、`\mathcal{L}` | 花体 |
| 阶跃 / 冲激 | `u(t)`、`\delta(t)` | 全书统一 |
| 变换对 | `f(t)\leftrightarrow F(\omega)` | 不用等号 |
| 初始条件 | `0^-`、`0^+` | 上标，不用 Unicode `⁻` |
| 卷积 | `*` | 不用 `·` 或 `×` |
| 收敛域 | `\mathrm{Re}(s)>-a` | 极点右侧开平面 |
| 积分下限 | `\int_{0^-}^{t}` | 含冲激时保留 `0^-` |

页面渲染层：`t2e()` 只渲染新插入的题干与选项容器，加 `ignoredClasses:['katex']` 保证幂等；`throwOnError:false` 避免红字错误外泄。本地 KaTeX 缺失时自动回退 CDN，两者都失败才降级为纯文本并显示提示条（降级只改文本节点，不破坏选项点击事件）。

### 图形题干

8 个图形题模 `g01`–`g08`：波形判能量/功率信号、冲激采样读图、框图判系统特性、卷积结果读图、离散频谱读周期、Sa 频谱读零点、抽样频谱判混叠、零极点图判稳定。图形由 `figWave()` / `figSpec()` / `figBlock()` / `figPoleZero()` 按题目参数实时绘制成内联 SVG，零外部图片依赖。

- **校验**：`figIssues()` 要求完整 `<svg>…</svg>`，并拦截 `<script>`、`on…=` 事件属性、`javascript:` 协议；不合规的题直接丢弃重试
- **去重**：`signature()` 把 SVG 里的文字标注和长度一起纳入指纹，避免「题干相同但图不同」被误判为重复题
- **保底**：开启「含图形题」时，每轮至少保证约 20% 图形题（替换同轮文字题，题量不变），避免随机抽题导致整轮看不到图
- **统一字体**：图内数学标注（`τ`、`T`、`ω_1`、`f_s`、`x(t)`、`\mathrm{Re}(s)` 等）生成期只写 LaTeX，渲染期由 `renderFigTex()` 换成绝对定位的 KaTeX 覆盖层，与正文共用同一套数学字体；只有纯中文或几何说明（「负反馈」、「× 极点 ○ 零点」）保留普通文字。不再使用 Unicode 上下标或系统字体的变量字母
- **图注**：数学符号一律由 `M()` 包成公式，纯文本里不出现 `τ`、`A`、`s 平面` 这类裸符号

### 讲解助手（边做边问）

做题页右下角「问一问」打开面板。宽屏（≥1120px）下题目区会自动左移让出空间，面板真正「在旁边」，不遮挡图形；窄屏仍是浮层，可随时收起。

- **内置离线讲解**（默认，不联网可用）：递进提示（方向 → 关键公式 → 完整解析，学生没要答案时不剧透）、知识点讲解（`KP_LESSONS`）、前置依赖与掌握度、选项分析、符号规范、完整解析；也支持直接打字提问，按关键词路由到对应回答
- **可选 AI 接入**：首页「AI 讲解设置」或面板齿轮里填 OpenAI 兼容 `/v1/chat/completions` 地址、Key、模型名。上下文自动带当前题目、选项、解析、知识点、前置与作答情况，并提示模型先给思路、不直接说答案
- **失败回退**：接口超时（25 秒）或报错时自动切回内置讲解并说明原因；「测试连接」不会改变运行时配置
- **安全**：Key 只存本机浏览器 `localStorage`，请求直接发到你填的接口；面板内可一键「改用内置讲解」。请只在可信设备上填写，不要用生产密钥

## 校验与兜底

生成链路的每一层都有保护，保证页面永远有题可答、题目结构永不走形：

1. **生成函数抛错** → `try/catch` 捕获，跳过该题模重试
2. **格式不符** → `normalizeQuestion()` 校验题干/解析/正确项非空、干扰项恰好 3 个且都是非空字符串、`kp` 合法、难度合法；有图时还校验图形容器、SVG 完整性、图内公式规范性与图注存在；任一不符返回 `null`，丢弃重试
3. **符号不规范** → `texIssues()` 检查 `\(...\)` 配对、公式块外是否残留 LaTeX 命令或 Unicode 上下标，并按 GB 3102.11 检查公式块内的正斜体（裸 `e`、`j`、`d` 一律拦截）；不合规直接丢弃重试，绝不放行到页面
4. **选项内容重复** → 用 `stripTex()` 归一化后去重比对（会把 `\frac{1}{2}` 与 `\dfrac{1}{2}` 视作同一内容，但保留分式括号结构，不会把 `\dfrac{\pi}{2}` 误判成 `2\pi`），重复即丢弃重试
5. **本轮题目重复** → 用 `signature()`（题干 + 图形指纹 + 排序后的选项集，忽略选项顺序）去重，重复即重试
6. **与上一轮重复** → 软避让：优先跳过，超过 40 次后放宽，避免无限循环
7. **配置交集为空** → 依次放宽知识点范围、题型，并在标题提示「配置已自动放宽」
8. **数量仍不足** → 用 `FALLBACK` 兜底题补足，标题显示「去重后 N 题」
9. **图形题保底** → 开启时补足到约 20%，保证读图能力真的被用到
10. **生成上限** → `maxAttempts = count×60 + 120`，防止死循环
11. **错因缺失 / 非法** → `misFor()` 校验长度与 id 合法性，非法显式 `mis` 回落到登记表或题型兜底，保证每个错误选项都带错因；洗牌时错因与选项文本一起移动，`mis[a]` 恒为 `null`

## 阶段 A：错因驱动的诊断

之前系统只使用「对 / 错」一个信号，诊断质量的上限由「题目到知识点的映射」决定。阶段 A 把**错因做成一等公民**：不只看哪个知识点错了，还看错在哪一步。

### 错因分类法（`MIS`）

12 类，覆盖第 1–4 章高频难点：概念对象混淆、性质 / 公式记反、时频域映射错误、线性 / 时不变判据混淆、积分限与重叠区间、常数系数与单位、收敛域与存在条件、极点与稳定性判据、读图与表征转换、代入与代数计算、前置数学知识缺口、套路迁移失败。每类有 `name / desc / fix`：描述症状，给出**可执行的改正动作**，而不是笼统的「多刷题」。

分类依据：郑君里教材常见难点，以及 threshold concepts、时频域映射障碍、卷积积分限误解、`time invariant` 字面误解、收敛域漏写、复数代数前置不足、套路迁移失败等学习难点调研结论。文案里不写裸数学符号，与「图注 / UI 名称去裸公式」的既有约定一致。

### 干扰项绑定（`MIS_MAP` / `misFor()`）

`MIS_MAP` 为全部 39 个题模的三个干扰项各登记一个错因 id，顺序与 `gen()` 返回的 `distractors` 一致。优先级：

1. 题模 `gen()` 显式返回 `mis: ['m01','m02','m03']`（最精确，供以后加题用）
2. `MIS_MAP[tpl.id]` 登记表
3. 兜底：按题型给默认错因（`concept→m01`、`calc→m10`、`property→m02`、`system→m04`），图形题首项给 `m09`；非法标签一律回落到兜底

`normalizeQuestion()` 把「选项文本 + 错因」绑成一个整体再洗牌，所以 **`q.mis[i]` 永远对应 `q.opts[i]`，`q.mis[q.a] === null`**。这是阶段 A 的核心不变量，专项回归里洗牌 40 次逐项验证。

### Q-matrix（`qkps()` / `kpWeighted()`）

每题带 `kps: [{id, w}]`：主知识点权重 1，直接前置知识点权重 0.35。一道题答错，前置知识点也收到一份较弱的证据。`kpWeighted()` 据此给出「计入前置依赖后的加权表现」，用来判断拖后腿的是本体还是前置；**它只做补充观察，不改变 `weakKPs()` 的判定**，「本轮有错题必进处方」的保证不受影响。

### 隔离题 / 综合题（`SCOPE_MAP`）

`iso` 只考单个知识点、一步可得；`int` 跨知识点、多步推导，或需要读图转换表征。39 个题模逐个登记，未登记的图形题默认 `int`、文字题默认 `iso`。

报告新增对比表：按知识点分列两类题的正确率并给出判读——隔离题与综合题都差是「概念没建立」，隔离题好、综合题差是「会认不会用」（对应错因 `m12` 套路迁移失败），隔离题差反而综合题好则多半是粗心或猜测。处方据此提示：会认不会用时优先做变式与跨知识点题，不要重复刷同型隔离题。这一对比把「不会」拆成两种完全不同的补救路径。

### 报告与讲解

- **错因画像**：按累计次数排序，显示每类错因的症状、改正动作、常出现在哪些知识点，以及本轮新增次数；末尾列出「尚未触发的错因」——某类干扰项长期无人选择，说明它太容易被排除，可替换成更有迷惑性的同类选项（干扰项有效性的粗略观测）
- **隔离题 / 综合题对比**：区分「概念没建立」与「会认不会用」，见上节
- **处方按错因聚合**：薄弱知识点下先列出该知识点最高频的 1–2 类错因及对应动作，再列前置依赖、错题与资料
- **答题即时反馈**：答错时在解析前插入「错因定位」框
- **讲解助手**：新增「我为什么错」快捷按钮，定位本题错因并给出累计高频错因；「选项错在哪」也会先讲错因再给解析；`aiContext()` 把干扰项错因标签与学生本次错因一起发给模型，要求优先针对命中的错因纠正

### 兼容性与回归

`state.answers[q.id]` 新增 `mis`，`roundLog` 每条新增 `chosen / mis`，`qbank` 新增 `mis / kps`。旧版本存的历史记录缺少这些字段时，`misStats()` 跳过、`kpWeighted()` 按主知识点兜底，不会报错。

阶段 A 专项回归覆盖：12 类分类法完整性、39 题模错因与隔离/综合登记覆盖、错因优先级与兜底、Q-matrix 权重、洗牌 40 次绑定不漂移、6 轮全量生成与持久化、答题写入、累计 / 本轮统计、加权证据、隔离题与综合题对比判读、报告各区块、讲解助手接线、旧数据兼容。当前 **1681 项通过**；既有三套回归（1371 / 7 / 81 项）也全部通过。

## 掌握度规则

**两套口径，报告里都给出，避免单轮错题被历史正确率稀释：**

| | 含义 | 用途 |
|---|---|---|
| 累计掌握度 | `rate = 该知识点历史答对数 / 历史已答数`，统计范围是所有历史生成题（`state.qbank`） | 上方总览表、长期趋势 |
| 本轮表现 | `state.roundLog` 记录本轮每道题的 `{qid, kp, correct, chosen, mis}` | 触发诊断、列出本轮错题 |
| 错因画像 | `misStats()` 从 `answers[].mis` 聚合累计、从 `roundLog` 聚合本轮 | 错因画像卡片、按错因处方 |
| 加权证据 | `kpWeighted()` 按 Q-matrix 权重累加（主 1、前置 0.35） | 处方里的补充观察，不改判定 |

- 累计状态：`rate ≥ 0.8` 掌握 / `≥ 0.5` 不牢固 / `< 0.5` 薄弱 / 未作答为「未测」
- **本轮只要有错题，该知识点必定进入薄弱点处方**：错 2 题以上或本轮全错 → 「本轮薄弱」；错 1 题 → 「本轮不牢」
- 所以即使某知识点累计 4/5 已判「掌握」，本轮错 1 题仍会进处方（长期状态保留在总览表里，两者不冲突）
- 薄弱点处方优先级：先列前置依赖缺口 → 高频错因与改正动作 → 本轮错题 → 累计错题 → 加权表现 → 学习资料链接
- 作答记录按全局唯一 `id` 关联到 `qbank`，换题不会丢失统计

## 已知限制

- 只有选择题，主观推导题靠「自评」还没做
- 掌握度仍是简单正确率，不区分题目难度、不建模猜测与遗忘（阶段 B 解决）
- 错因由题模静态登记，不是从学生的自由文本里推断；讲不出「学生自己描述的错因」
- 单机单用户，没有跨设备同步
- 题模是参数化模板，不是 LLM 生成；题干措辞固定，变化来自数值、符号、图形参数与选项顺序
- 圆周率 `\pi` 按教材惯例保留斜体（标准要求正体，但常用字体无正体小写希腊字母）
- 讲解助手的开放式追问需自行接入 OpenAI 兼容接口；内置讲解是规则式回答，不是 LLM
